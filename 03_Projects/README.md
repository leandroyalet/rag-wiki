# Projects

A project = a team effort with a concrete goal and a clear owner. Typically lives 2–6 months. Examples:
- A systematic review on a subtopic.
- A comparative experiment of techniques.
- A paper or public report.
- An internal system (demo, prototype).

## Structure of each project

Each project is a **folder** with at least a `README.md` based on the `project` template. Suggested internal folders:

```
{project-name}/
├── README.md          # project dashboard
├── experiments/       # notes per experiment (one per file)
├── notes/             # working notes, brainstorming
├── figures/           # plots and figures generated
└── writeups/          # drafts that later migrate to 06_Outlines/
```
