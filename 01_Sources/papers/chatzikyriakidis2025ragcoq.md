> **Summary** Extracts structured RDF event representations from historical narratives (Thucydides) using three strategies: base LLM generation, knowledge-graph enhancement, and RAG. RAG improves precision and metadata completeness (vs. base generation's better coverage). An automated pipeline then converts extracted RDF into Coq proof assistant specifications for formal historical reasoning (causal verification, temporal arithmetic with BC dates). Tests GPT-4, Claude, Llama 3.2. Novel contribution: RDF → Coq translation pipeline enabling higher-order reasoning over event knowledge bases. Added as application note in [[02_Wiki/concepts/RDF]].
