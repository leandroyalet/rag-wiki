> **Out of scope for RAG wiki.** Interview study of 18 practitioners on how developers use requirements documents as LLM prompts for code generation. Key finding: requirements are too abstract for direct LLM input; developers manually decompose them into programming tasks. No retrieval, indexing, or document-processing concepts.
