# BM25

> **TL;DR** The dominant lexical ranking function — a probabilistic TF-IDF variant that saturates term frequency and penalises long documents. Standard baseline for sparse retrieval in every RAG pipeline.

## Definition
BM25 (Best Match 25, aka Okapi BM25) is a bag-of-words ranking function derived from the probabilistic relevance model. It scores a document `d` against query `q` by summing per-term scores that weight term frequency (TF), inverse document frequency (IDF), and document length normalisation.

## How it works

### Scoring formula
```
score(d, q) = Σ IDF(tᵢ) · [ f(tᵢ,d) · (k₁+1) ] / [ f(tᵢ,d) + k₁·(1 - b + b·|d|/avgdl) ]
```
- `f(tᵢ,d)` — term frequency of token `tᵢ` in document `d`.
- `IDF(tᵢ)` — log((N − df + 0.5) / (df + 0.5)) where N = corpus size, df = document frequency.
- `k₁` — TF saturation parameter (typically 1.2–2.0); limits the impact of very high TF.
- `b` — length normalisation parameter (typically 0.75); 0 = no normalisation, 1 = full.
- `avgdl` — average document length in the corpus.

### Key properties
- **TF saturation**: doubling term frequency gives diminishing returns, unlike raw TF-IDF.
- **Length normalisation**: longer documents are penalised so they don't dominate just by size.
- **No semantic understanding**: strictly lexical — synonyms and paraphrases score zero unless the exact token matches.

## Context in RAG
BM25 is the backbone of [[Sparse Retrieval]] and is used as:
- **Standalone retriever**: efficient first-stage retrieval via an inverted index (Elasticsearch, OpenSearch, Lucene, BM25S).
- **Hybrid search component**: combined with a dense retriever (cosine ANN) via [[Hybrid Search]]; fusion typically via [[Reciprocal Rank Fusion (RRF)]].
- **Baseline**: BEIR results show BM25 outperforms many zero-shot neural retrievers on out-of-domain datasets, making it the required baseline for new retrieval papers.

## Variants
| Variant | Change |
|---------|--------|
| **BM25+** | Adds a floor to TF weight to prevent zero scores for rare terms |
| **BM25L** | Alternative length normalisation; less aggressive than BM25 standard |
| **SPLADE** | Learned sparse representation trained to generalise BM25's bag-of-words signal [[Sparse Retrieval]] |

## Trade-offs
- ✅ Extremely fast with an inverted index; scales to billions of documents.
- ✅ No GPU, no embeddings, no fine-tuning required.
- ✅ Robust baseline — often competitive with zero-shot neural models.
- ❌ No semantic understanding: fails on synonyms, paraphrases, or cross-lingual queries.
- ❌ Sensitive to tokenisation and vocabulary mismatch.
